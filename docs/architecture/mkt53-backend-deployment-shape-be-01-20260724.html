mkt53 · BE-01 后端部署形态

Accepted local design · 静态前端保持不变 · 独立 Compose · 同源 API · PostgreSQL 双网络隔离

已选形态

  • • 复用现有主机，不并入共享 Lighthouse Compose
  • • 同源 /api/v1/，避免新域名和 CORS
  • • edge/data 双网络，API 与 DB 均无 host port
  • • 静态前端保留到 BE-06，支持一键退回 static

生产硬门禁

  • • portal identity/role 头必须真实可验，不能只依赖 204
  • • 外部身份头必须剥离，401/403 矩阵通过
  • • 密钥仅 root-only secret files，不进 bundle/image/log
  • • compose/nginx/DB 写入需要另行授权与回滚证据

数据保护与退出

  • • 每日逻辑备份 + 加密离机副本 + 隔离恢复演练
  • • 初始 RPO ≤ 24h、RTO ≤ 4h、availability 99.5%
  • • 增量预算护栏 ≤ ¥100/月，不以削减安全换成本
  • • 命中容量/SLO/合规阈值时先迁托管数据库
